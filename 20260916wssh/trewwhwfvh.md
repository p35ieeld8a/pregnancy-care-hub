# 益母草宫寒汤应该怎么做？

> 更新时间：2026-09-16 (UTC+8)

益母草宫寒汤的做法是比较简单的，首先需要先将益母草洗干净，在切成小段，最后放入砂锅中加入适量的清水进行熬煮10分钟后，可以加入适量的姜片后再用小火熬5分钟就可以了。益母草的主要功效是调经活血，可以改善宫寒的情况，益母草目前是妇科常用的中药材，它性味比较平和，长期服用的话是不会出现副作用的，可以说是女性治疗宫寒的一位很好的中药材。宫寒汤其实就是治疗女性宫寒的一种中药汤剂，主要就是由中药材所组成的，有宫寒的女性在喝了相关的宫寒汤后会起着很明显的作用。建议女性朋友可以在家尝试一下。
目前比较常见的宫寒汤有桂圆红豆大枣汤、乌骨鸡汤、黑枣山药生鱼汤等，一般去看中医的时候医生都会推荐这三种。自己在家就可以做，做法很简单。

## 宫寒汤做法

1、桂圆红豆大枣汤

- 1. 先准备好干的桂圆、大枣、红豆等，这里数量一般医生会根据你实际情况告知你；
- 2. 然后就需要把红豆泡十分钟后清洗干净备用；
- 3. 再把大枣去核，桂圆也是去壳去核备用；将洗好的红豆放进锅中，放入适量的清水煮沸；
- 4. 在依次放入大枣、桂圆，然后用大火熬煮60分钟就可以了。

2、乌骨鸡汤

- 1. 先准备哈一只乌鸡，然后在准备好当归、黄芪、茯苓等中药材；
- 2. 把乌鸡去内脏洗干净，把中药材放进乌鸡的肚子里面，用线或者是牙签封起来，放砂锅内煮熟1个小时；
- 3. 最后用锅炉网去掉渣，根据自己的自豪加入调味就可以了。

3、黑枣山药生鱼汤

- 1. 准备好一条鲫鱼、山药、黑枣适量等；
- 2. 把鲫鱼去磷，内脏清洗干净备用；
- 3. 把山药去皮切小块和黑枣泡于水中；
- 4. 然后煎锅倒少许油，把鱼放进去煎至两面金黄；
- 5. 再把山药、生鱼、黑枣一起倒锅中,倒入热开水；
- 6. 煮至汤色变浓白,下盐调味与撒入枸杞关火。

以上就是几种宫寒汤的做法，做法可以说是比较简单的，有这方面需求的女性可以尝试一下。宫寒是一件很大的事情，严重的话是会引起不孕不育的，所以一定要重视起来。
