# 宝宝便秘别再吃香蕉了！其实真正管用的方法还是这些...

> 更新时间：2026-09-19 (UTC+8)

**喜欢就点个****关注****吧**

哎呀，怎么办，宝宝好像又便秘了！

给她多吃点香蕉吧，能通便！

给她喝点蜂蜜也可以。

应对便秘，人们似乎很习惯的借用香蕉、蜂蜜等方法来通便。

然而，这些方法到底用处有多大呢？

是不是只要娃几天不排便就是便秘啦？

娃娃便秘该怎么办？吃啥水果呢？

别急！今天这篇干货满满的关于宝宝便秘的内容应该能解决您的疑问。

1

**常说的通便方式到底有用吗**

**01便秘吃香蕉有用吗？**

**便秘吃香蕉，可能非但不通便，反而可引起或加重便秘！**

预防和治疗便秘的关键是摄入大量的纤维素！

然而，香蕉中膳食纤维的含量非常少，同时又含有能抑制胃肠液的分泌并抑制其蠕动的单宁，不仅不能帮助通便，反而具有一定的收敛作用，对止泻有一定的帮助。

**简而言之：香蕉不但不通便，反而会造成便秘！**

**每100g纤维素含量**

苹果

1.3g

猕猴桃

1.4g

香蕉

2.6g

梨子

3.1g

牛油果

6.7g

西梅

7.1g

相比之下，西梅、牛油果、苹果、梨是更好的缓解和预防便秘的水果选择。

当然还有如西兰花、南瓜、红薯等高纤维的蔬菜，也是不错的选择。

**02喝蜂蜜能通便吗？**

**蜂蜜虽有润肠作用，但并不是人人能用，人人都有效！**

**周岁内宝宝禁用！**

由于1岁以内婴儿肠道微生物生态群仍在完善，容易让蜂蜜酿造、运输与储存过程中产生的肉毒杆菌在肠道中繁殖，产生毒素并引起中毒。

**过敏体质宝宝慎用！**

**过敏体质的宝宝**食用后有可能会引起过敏。

**蜂蜜仅对果糖不耐受的人群有用！**

蜂蜜的通便作用主要是因为果糖成分的作用，但是仅对果糖不耐受的人群来说有用，且至少要吃几十克才能更好的通便。

这也就是为什么蜂蜜通便对有些人来说有效果，对有些人来说效果不明显。

**03益生菌，不是想用就能用的！**

宝宝便秘了，看着确实心疼。益生菌或许有缓解便秘的作用，但在儿童便秘的临床应用上缺乏循证医学依据，也就是说证据不足。

益生菌更适合在宝宝肠道功能紊乱如腹泻、消化不良、使用抗生素引起腹泻时使用。

对于2 岁以下尚处于肠道菌群建立阶段的宝宝来说，除非特殊情况，一般是不建议额外补充益生菌。

因为，不合理使用益生菌制剂，去刻意营造肠道菌群平衡，反而让宝宝因此失去自己建立正常肠道菌落的能力，有点得不偿失。

相比于益生菌去改善宝宝便秘，还不如让宝宝多吃一些富含膳食纤维的食物，如芦笋、菠菜、草莓等可以刺激人体结肠内常驻菌群的生长和活性的食物。

2

**娃几天不排便就是便秘吗？**

不一定！

判断宝宝是不是便秘关键还是看这几点。

**①排便时的费力程度；**

**②便便的性状；**

若宝宝每次大便都很费劲，很不舒服、很痛苦，且排出来的大便很干燥，一粒一粒的，有的甚至是一个小硬球，

这样即使宝宝每天排便，也是便秘哦。

**相反，若宝宝偶尔几天不排便，但排出来的大便性状软黄，无硬结，排便时也无痛苦，那家长无需过于太担心，宝宝并不便秘了。**

但是，如果娃娃不幸确实存在便秘的情况，这就需要家长引起重视了。

及时找到原因，对症处理，及时缓解娃娃便秘情况。

3

**宝宝便秘了该怎么办**

**01保障膳食纤维的摄入**

注意纤维素的摄入，有助于预防和缓解宝宝便秘！

纤维素在宝宝肠道中被肠道菌群败解，会产生水和短链脂肪酸，能够使大便变软，易于排出。

因此，给宝宝添加的辅食，注意多添加一些高纤维的食物如西梅、猕猴桃、火龙果、燕麦、红薯、豆类、西兰花、亚麻籽、菠菜、芥蓝、小白菜等。

另外，要注意辅食的烹饪方法，辅食不要蒸煮得过烂以便保留食物中原有的纤维素。

**02让宝宝适当运动**

平时让宝宝多运动，帮宝宝进行腹部按摩等，有利于增加肠蠕动，同时让宝宝养成定时排便的习惯，有助于改善宝宝便秘的情况。

**03便秘特别严重时可引入开塞露等**

如果宝宝便秘很严重，千万别让宝宝硬拉，一来宝宝不舒服，二来容易造成肛裂。

此时，可以先用一下开塞露或其他安全的手段（如服用乳果糖），帮宝宝把积压在肠道里的干结的粪便排出。

但是开塞露、乳果糖之类方法，只是救急，并非长久之计。

改善便秘还要从饮食上下手改善，增加纤维素摄入，逐渐减少宝宝大便干燥的情况。

**注意了，若是宝宝保障了足量的摄入了膳食纤维摄入，但便秘情况缓解不明显的情况。**

需要家长注意以下几种特殊情况：

**01注意肛肠疾病导致便秘的可能**

注意了，如果宝宝总是憋着不拉，而且宝宝排出的大便开头较干，最后面是芝麻酱样的话，可能是宝宝排便时的不适感导致宝宝不愿意排便。

家长可以仔细观察宝宝的便便及排便时的情绪。

若发现宝宝大便带血丝，宝宝可能存在肛裂了，家长这时定要带宝宝到医院就诊治疗。

**02存在紧张情绪引发结肠罢工的可能**

另外，还需要家长警惕娃长时间处于紧张情绪下可能引发引起结肠罢工。

比如：

妈妈突然上班，把宝宝交给保姆看管

刚刚送到幼儿园，产生分离焦虑

父母脾气不好，经常吵闹

父母对宝宝管教过于严厉

对宝宝排便问题疏于管理，宝宝贪玩，即使有了便意也顾不上排；

这种情况下引发的宝宝便秘，就需要家长尽可能的想办法给宝宝缓解焦虑的情绪了，以便回复结肠功能。

尽量稳定宝宝的看护人，避免情绪焦虑。

若迫不得已情况下，妈妈一定要好好的和宝宝沟通，让宝宝正确意识到和妈妈间分离只是短暂的，且即便是分离妈妈也是爱他的哦。

至于父母脾气不好，经常吵闹、给宝宝极大严厉等情况，则需要家长在宝宝面前一定要注意控制情绪。。

类似处理方法，缓解宝宝情绪焦虑。

**03存在药品导致肠道收缩无力的可能**

娃如服用抗胆碱能类药，如阿托品、颠茄等、存在慢性铅中毒、克汀病（甲低）等可引起便秘。

在给娃服用抗胆碱能药物时，一定要要严格按照医嘱用药，切不可自行更改用量及用药时间。

慢性铅中毒、克汀病需要医学干预。

**结语**

看完的家长赶紧对照娃的情况自查哦！

其实，多数情况下，娃便秘时由食物太精细，缺少果蔬、憋便、久坐，缺乏运动等“恶习”引起的。

因此，日常生活中，为了预防宝宝便秘，家长应尽可能保障宝宝纤维素的摄入，适当的给宝宝做腹部顺时针按摩运动以及帮宝宝建立良好的排便习惯。

希望萌宝成长路上都有父母相伴
