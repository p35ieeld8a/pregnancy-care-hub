# 做三代试管总共要去几次医院，上班族怎么请假？

 三代试管的流程

 三代试管婴儿是指利用第三代辅助生殖技术，通过胚胎基因检测筛选健康的胚胎进行移植。整个流程一般分为多个步骤：

1. 体外受精（IVF）: 女性通过促排卵药物刺激卵巢产生成熟的卵子，医生将卵子和婴性的精液在实验室中混合受精，形成胚胎。
2. 胚胎培养: 受精后，胚胎在实验室内进行培养，观察其发育情况。
3. 基因检测 (PGD): 在胚胎发育到一定阶段时，可以进行基因检测，筛查胚胎是否存在遗传性疾病。
4. 选择优质胚胎: 根据基因检测结果和胚胎形态学评估，选择健康的胚胎进行移植。
5. 胚胎移植: 将筛选好的胚胎移植到女性子宫内。
6. 妊娠监测: 移植后，通过血清hCG检测、B超等手段监测妊娠情况。

 整个流程需要多次前往医院检查和治疗，具体次数因个人情况而异。一般来说，三代试管婴儿的周期大约需要3-4个月的时间完成。

 上班族请假安排

 对于上班族来说，如何平衡工作与生育计划是一个重要的考量因素。以下是一些建议:

 提前沟通: 与你的领导和同事沟通你的试管婴儿计划，提前预定休假时间，尽量减少对工作的影响。
 合理安排行程: 尽量将检查和治疗安排在非工作日或工作结束后的时间段，以确保能够正常上班。
 利用远程办公: 如果工作性质允许，可以尝试利用远程办公的方式，在休假期间继续完成一些任务。

 三代试管费用流程及移植过程

 三代试管婴儿的费用是一个比较重要的考量因素，一般需要考虑以下几个部分:

 促排卵药物费用: 约为5000元
 取卵和取精费用: 约为10000元

 胚胎培养费用: 约为8000元
 基因检测费用: 约为20000元
 胚胎移植费用: 约为5000元

 总费用在9万元左右。

 三代试管的移植过程需要进行一系列的操作，包括：

1. 子宫内膜评估: 为了确保子宫环境适合胚胎着床，医生会通过B超检查评估子宫内膜厚度。
2. 胚胎移植: 将筛选好的胚胎通过细长的导管移植到女性子宫内。
3. 休息和监测: 移植后需要进行一段时间卧床休息，并定期接受血清hCG检测、B超等监测妊娠情况。
