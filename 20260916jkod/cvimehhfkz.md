# 【育儿】宝宝缺钙铁锌怎么办？ 专家教你科学食补法则

> 更新时间：2026-09-16 (UTC+8)

生活中不少父母都感叹小儿难养，父母难当，皆因宝宝一点小毛病都反复难愈，让他们束手无策。学会合理为宝宝安排膳食营养，无疑是让他们身体健壮、远离病痛的关键一步!广州医科大学附属第三医院儿科专家张少冰主任作客家庭医生在线，详细解答了网友关于宝宝饮食、营养方面的疑问!宝宝营养元素缺失 食物补充最靠谱　　婴幼儿时期，生长发育迅速，代谢旺盛，对各种营养和能量的需求比成人还要多。钙、铁、锌是孩子生长不可或缺的营养元素，但家长如何判断宝宝是否缺乏某种营养素?怎样补充才最恰当呢?　　张少冰主任介绍，要明确是否缺钙和锌，建议最好到医院做相应检查。检查钙最可信的方法是，血液中的25羟D或拍片看看四肢骨垢的情况。而判断是否缺锌，主要是参考血液中的微量元素值。　　儿童补钙，可根据相应年龄补充足够的奶量，如果是阳光不充足的地区，可另外补充维生素D。而锌主要来源于肉类，因此建议每天要补充肉类、动物肝脏、蛋黄等食物。　　宝宝对铁的需求量相当大，张主任表示，补铁最佳的途径是从肉类中摄取，如动物肝脏和血制品，这些都是含铁量相当高的食物。而植物中如木耳、红枣等也都富含铁质。但张主任强调，从肉类中所摄取的铁质相对来说会更容易被人体吸收利用。因此建议，儿童每周摄入约4块腐乳大小的动物类肝脏(如鸡肝、猪肝)，分开5~7天喂予。蔬菜摄取不足易缺乏纤维素 专家支招搞定挑食宝宝　　孩子不爱吃蔬菜易致纤维素缺乏，这会导致肠蠕动减慢引起大便秘结。家长用强迫或者诱骗的方式让孩子吃蔬菜，这只会让孩子更加反感。张主任在此给各位家长支招，用简单的方法就能引导孩子爱上蔬菜，首先要和小朋友说明吃蔬菜对身体的重要性。其次，一定要把蔬菜烹饪得口感良好，宝宝才能有好胃口。　　聪明大脑不能光靠食补 开发智力还需强化母婴配合　　家长都期盼小孩有聪明过人的头脑，成绩出众。本期答疑活动中，不少家长都很关心到底吃什么有益于宝宝智力开发呢?张少冰主任表示，饮食上像深海鱼、干果类、蛋黄等食物都富含DHA有助大脑发育。　　但张主任同时强调，儿童智力的开发是需要从生活常识中培养，而并非单纯依赖食物，强化母婴配合和增加与幼儿沟通都是开发小儿智力的关键因素。并且，智力的好坏也取决于孩子身体机能的好坏，因此合理的营养分配很重要。宝宝便秘顽固 先查有无肠道发育异常　　婴幼儿由于肠蠕动功能不健全，加上肠道菌群易受外界影响，便秘的发生率会明显高于成年人，不少家长都想寻求一个解决便秘的良策。为此，张少冰主任表示，便秘的原因很多，最常见的是，饮食和消化功能不配套。　　张主任告诉家庭医生在线网友，如果母乳喂养出现便秘，建议先做肛门检查，看看有无肠道发育异常。如检查无异常，首先看看母亲有没有便秘的问题存在，一般来说如果母体便秘，小孩也会出现同样情况。　　如果人工喂养，则需要调整一下奶粉的配方，可以食用水解配方的奶粉，这样更有利于宝宝胃肠道的吸收和消化，有助减少便秘。本文来源于家庭医生在线
